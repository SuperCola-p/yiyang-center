## 补充调查：/page/clients "response already committed" 错误排查

### 根因确认
- **导致 error**：IDEA 使用捆绑 JDK 26 编译项目，Lombok 1.18.30 不兼容 JDK 21+ → `ExceptionInInitializerError` (com.sun.tools.javac.code.TypeTag :: UNKNOWN) → 模板渲染过程中抛出异常，但部分 HTML 已输出（response committed）→ Spring Boot 无法再渲染错误页面
- **Maven 命令行已验证**：`mvn spring-boot:run` 启动在 8080 端口，应用正常运行，login + /page/clients 页面渲染 + /api/clients 接口全部正常返回

### 关键发现
- **WorkBuddy 环境变量**：`SERVER__PORT=61862` 覆盖了 application.yml 中的 8080（之前 61862 端口被占用导致无法启动）
- **Spring Shell 冲突**：`mvn spring-boot:run -Dspring-boot.run.arguments="--server.port=8080"` 会被 Spring Shell 解析为命令（`No command found for '--server.port=8080'`），必须用 `SERVER_PORT=8080 mvn spring-boot:run` 方式启动
- **CSS 重复引用**：`client/list.html` 的 DataTables CSS 在最终 HTML 中出现两次，原因是 Thymeleaf Layout Dialect 同时通过 head-extra fragment 替换和子模板 head 内容追加两种机制引入了同一 CSS
